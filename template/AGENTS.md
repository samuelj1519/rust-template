# Agent instructions

Confirm the repository, branch, existing changes, task scope, authorization, and project standards before editing. Preserve other people's work and follow scope-specific AGENTS.md files. Read CONTRIBUTING.md before maintenance when it is present.

Use Cargo's native commands. Run formatting, strict Clippy, all target tests, and separate documentation tests. Preserve existing tests and assertions. For specification-driven test migration, identify the affected behavior and replacement protection.

Workspace members inherit the lint policy. Apply the task's authorization to dependencies, license allowlist additions, quality-policy changes, installations, commits, integration, remote operations, publication, and real data. Use normal hooks; obtain explicit approval for quality reductions and history rewrites.

Use synthetic fixtures and independent source/build directories. Verify the actual compiled and executed artifact. Wait for explicit asynchronous completion and query an unknown operation result before retrying it.

Use a new, independent reviewer session for nontrivial changes. Record decisions, verification, failures, and remaining checks in the task or review record. Store runtime logs and build output in artifact directories excluded from Git. Keep guides focused on current usage and constraints.
